Harak native fonts
==================
The native Harak theme uses subset-merged OFL fonts distributed with the
owner's LG reference application at Alaaaya/Alaa-LG-TV-Player,
hark/qa-2.7.1, reference commit 1b0169b2.

plex.ttf: IBM Plex Sans Arabic regular Arabic, extended-Latin and Latin
subsets merged with fontTools. The modified font's internal family is
Harak Body, avoiding the reserved name Plex.
Source license https://github.com/IBM/plex/blob/master/packages/plex-sans-arabic/LICENSE.txt

kufi.ttf: Reem Kufi Arabic, extended-Latin and Latin variable subsets
instanced at weight 600 and merged with fontTools. Internal family renamed
Harak Heading.
Source license https://github.com/aliftype/reem-kufi/blob/main/OFL.txt

Both fonts remain SIL Open Font License 1.1. Full copyright notices and
licenses are included alongside this file.
