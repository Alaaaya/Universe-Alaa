universe-Alaa, independent Android TV design preview

Phase 1 is Home and Live only. Kotlin, native Android Views, native focus targets, Material icons and an original orbit/play mark. Layout is always LTR, including Arabic. Source was written from the analyst's description and abstract layout inventory, never imported from decompiled implementation or extracted assets.

Home preserves the six-module horizontal row below the 60% guideline, account/date above, weather area right, centered brand. Live preserves the 50% split, upper-right inline preview, below-preview name/favorite/description, modal 35% category drawer, vertical channels. Category data and channel names are fictional fixtures. Weather is disabled, pairing is marked DEMO ONLY, and activation is explicitly pending. No EPG, false program metadata, provider logos, telemetry or location requests.

OK on a channel selects it; another OK opens the placeholder fullscreen. Back returns through fullscreen/drawer/Live/Home. Left opens categories; Right reaches favorite; Up/Down traverse channels. The nine-row viewport scrolls through twelve fixtures. Native focus backgrounds are rectangular translucent gold. Nonimplemented modules say next phase rather than pretending to function.

This phase does not implement network playback, Media3, VLC, Room, Xtream/M3U import, secure pairing, panel channel administration, expiry enforcement or production device identity. Those are the planned next milestones, not completed features. The MAC-style string is only an obvious demo installation label, never a hardware MAC or credential. No INTERNET permission is present in this UI-only preview.

Build locally with ANDROID_HOME=/home/kit/android-sdk ./gradlew :app:compileDebugKotlin :app:testDebugUnitTest --no-daemon, one Gradle process only, Kotlin in-process, max heap 3GB. The local.properties file is ignored. Compile/test output only, no release or deployment.

Screenshots are generated by the actual Android view code in Robolectric Native Graphics API 28 at 1920x1080, not browser recreations. They are simulator renders and NOT proof of physical Android TV rendering, decoding, smoothness, or performance. Reference diagrams are independently reconstructed from static analysis and NOT actual Universe 8K Gold screenshots. No pixel-identity claim is possible without a lawful runtime reference capture.
