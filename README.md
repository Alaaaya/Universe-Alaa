universe-Alaa, independent Android TV player

Native Kotlin Android Views, Media3 playback and Android Keystore encrypted provider storage. Layout stays LTR in Arabic. Red is the default; Gold, Blue, Royal Blue and Sunset Prayer remain selectable. The prayer Home uses the existing Mawaqit cache and contains no tile-floor reflections.

Connect an Xtream server/account or an M3U URL using Change Server. HTTPS is required unless the user explicitly permits insecure HTTP for that playlist. Credentials are stored locally with AES-GCM under an Android Keystore key, outside Android backup. They are never bundled into the APK. Removal clears stored provider credentials and cached catalogue data after confirmation.

Catalogue cache loads first and each foreground opening silently refreshes in the background. Large Xtream arrays are parsed incrementally. Encrypted, bounded catalogue chunks are staged before an atomic manifest commit, so a failed refresh retains the previous list. Movie/series posters load from the provider on demand, with memory caching only. Paging bounds the number of native Views. The current snapshot interface still keeps decoded catalogue entries in memory; low-memory TV hardware needs testing with large accounts.

Live TV supports an inline preview, fullscreen, favorites/recent lists and channel zapping. Hold OK on a channel or category for its options menu, then choose نقل to move it with Up/Down; OK saves and Back cancels. Channel menus also toggle favorites, and the Favorites list supports the same saved order. Saved order survives playlist refresh and cache reopening. See docs/REORDER.md. Movies open a detail/play route. Series load actual provider seasons and episodes, with encrypted offline episode caches. M3U files preserve complete stream URLs but do not invent a structured series catalogue. Embedded audio and subtitles are selected from tracks exposed by Media3. Codec support ultimately depends on the Android TV decoder. Channel Up/Down zap live channels; hidden-control Left/Right seek VOD by ten seconds. Menu opens tracks, Captions opens subtitles, and Back returns to the previous screen.

Secure remote panel pairing and per-device hidden Xtream categories are supported; see docs/SECURE-PAIRING.md and docs/HIDDEN-CATEGORIES.md. Push notifications, EPG and independent per-channel administration are not included. Weather is unavailable rather than fictional. Subscription name and expiry come from the actual account. Preview fixtures remain opt-in only in simulator tests; production starts disconnected.

Build with ANDROID_HOME=/home/kit/android-sdk ./gradlew --no-daemon :app:testDebugUnitTest :app:assembleDebug. Use only one Gradle process, Kotlin in-process and a 3GB maximum Gradle heap. Unit tests use Robolectric Native Graphics. RealProviderTest is opt-in when a private fixture exists outside the repository; its inputs are never packaged. Native simulator screenshots are not proof of physical Android TV playback or performance. No pixel-identity claim is made for the reference design.

Implementation and assets are independent of the analyzed third-party APK. See NOTICE.txt for icon provenance and docs/SECURE-PAIRING.md for the separate backend boundary. No public deployment or repository push is part of this local phase.
